Admin responsibilities

Publish clear tasks, review each submission before rewarding it, and verify real bank transfers before marking withdrawals as paid.

Approving a submission credits the reward to the member's server-side balance. A withdrawal request reserves the balance; rejecting it refunds the member. Marking it paid records the admin decision but does not send money automatically.
